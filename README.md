# document-Summarizer

A small Express app that accepts a PDF upload, extracts text, and generates a readable summary with important topics, key points, and short summaries.

## Run locally

1. Install dependencies with `npm install`
2. Start the server with `npm start`
3. Open `http://localhost:3000`

## Notes

- This works best with text-based PDFs, not scanned image PDFs.
- Uploaded files are processed in memory and are not saved to disk.
